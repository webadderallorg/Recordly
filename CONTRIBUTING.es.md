# Directrices para contribuir

¡Gracias por considerar contribuir a este proyecto! Tus aportes ayudan a mejorarlo para todas las personas. Revisa estas directrices para facilitar el proceso de contribución.

Áreas donde la ayuda es especialmente valiosa:
- Optimización de la exportación
- Grabación de pantalla nativa para Linux
- Aportes de fondos de pantalla
- Extensiones (marcos de dispositivos, efectos de clic y puntos de integración con el renderizado; consulta [EXTENSIONS.es.md](./EXTENSIONS.es.md))

## Cómo contribuir

1. **Crea un fork del repositorio**
   - Haz clic en el botón "Fork", en la parte superior derecha del repositorio, para crear tu propia copia.

2. **Clona tu fork**
   - Clona tu copia del repositorio en tu equipo:
     ```bash
     git clone https://github.com/your-username/Recordly.git
     ```

3. **Crea una rama nueva**
   - Crea una rama para tu nueva función o corrección de errores:
     ```bash
     git checkout -b feature/your-feature-name
     ```

4. **Realiza los cambios**
   - Implementa tus cambios.

5. **Prueba tus cambios**
   - Prueba los cambios cuidadosamente para comprobar que funcionan como se espera y que no afectan las funciones existentes.

6. **Crea un commit con tus cambios**
   - Guarda los cambios en un commit con un mensaje claro y conciso:
     ```bash
     git add .
     git commit -m "Add a brief description of your changes"
     ```

7. **Sube tus cambios**
   - Sube la rama a tu fork del repositorio:
     ```bash
     git push origin feature/your-feature-name
     ```

8. **Abre un pull request**
   - Ve al repositorio original y abre un pull request desde tu rama. Incluye una descripción clara de los cambios y del problema que resuelven.

## Cómo reportar problemas

Si encuentras un error o quieres solicitar una nueva función, abre un issue en la sección [Issues](https://github.com/webadderallorg/Recordly/issues) del repositorio. Proporciona todos los detalles posibles para ayudarnos a abordar el problema de manera eficaz.
