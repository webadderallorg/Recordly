# TikTok Sans

Unmodified TikTok Sans variable TrueType font, produced and maintained by TikTok.
Bundled locally for the TikTok caption preset; no font service is contacted at runtime.

- Official project: https://github.com/tiktok/TikTokSans
- Official release announcement: https://developers.tiktok.com/blog/tiktok-sans-open-source
- Distribution: [Google Fonts](https://github.com/google/fonts/tree/2750b521bd22ce141f12617194ab0e04cf5d12d5/ofl/tiktoksans)
- Pinned distribution commit: `2750b521bd22ce141f12617194ab0e04cf5d12d5`
- Original filename: `TikTokSans[opsz,slnt,wdth,wght].ttf`
- Local filename: `TikTokSans-Variable.ttf`
- Size: 761,964 bytes
- SHA-256: `0e7f0a3e924c9a86478fc6fc2946de2e4ab8fc704ed72ee40434ade94bb9b0c6`
- Axes: optical size, slant, width and weight (300–900).
- Script coverage: Latin, Greek and Cyrillic. Other scripts use the caption fallback family.
