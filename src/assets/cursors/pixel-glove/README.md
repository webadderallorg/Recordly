# Pixel Glove

Based on [ComixCursors](https://github.com/lzlrd/comixcursors), revision 22deda869aab704329a7c534ea0d1087fbcb4563.
Copyright Jens Luetkens and contributors; GPL-3.0-or-later. Original SVG sources,
COPYING, LICENSE.GPL and AUTHORS are included.

Recordly changes: render white/light-grey gloves at 48 × 48; remove blurred
shadows; quantize to four greys and binary alpha for crisp pixel edges. The PNGs
are the runtime assets; adjacent SVGs preserve upstream source. Original hotspots
are retained. Arrow uses the pointing glove; open-hand and closed-hand use
all-scroll and grabbing. Clicking briefly closes the glove when bounce is enabled.
This is a Comix cursor theme adaptation, not a Disney asset.
