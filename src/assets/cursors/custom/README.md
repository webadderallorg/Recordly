# Touch cursor source

`apple-ipad-pointer.png` is the unmodified 38 × 38 transparent PNG published by
Apple in “Use a Bluetooth mouse or trackpad with your iPad”.

- Article: https://support.apple.com/en-gb/105004
- Original file: https://cdsassets.apple.com/live/7WUAS350/images/ipad/ipad/ios13-ipad-mouse-connected-circular-pointer-icon.png
- Retrieved: 2026-10-19

This is Apple's support illustration of the circular pointer, not an extracted
iPadOS system resource. The runtime pointer also adapts its material to the
background; this static image does not reproduce that behavior. `touch-cursor.svg` embeds the unmodified PNG and adds a subtle white rim and
soft shadow. The same SVG is used by the picker, preview, and export. Ownership remains with Apple; this
source note does not grant a redistribution license.
