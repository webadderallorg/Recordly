# Bold Outline

Custom vector artwork following the user-provided cursor reference: pure black
outlines, white interiors, and rounded corners. The arrow has a broad triangular
body with a shallow notch. The pointing hand is rotated 25 degrees
left to follow the arrow direction. Both SVGs have tight canvases and a 512px
intrinsic height for crisp editor previews and exports.

Hotspots in SVG viewBox coordinates (before subtracting its origin):
- Arrow: (14, 5), at the tip.
- Pointer: (22.943454, 3.734231), the index fingertip after rotation.

The renderer uses the hand for pointer, open-hand and closed-hand telemetry;
other states use the arrow, following the existing two-image pack convention.
