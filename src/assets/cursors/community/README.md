## bee

Source: https://github.com/ful1e5/Bibata-Bee-Cursor

Revision: `2aa73cf4fe0ccffa9169e150c2018eb923badcbc`. See `bee/LICENSE`.

## catppuccin-pink

Source: https://github.com/catppuccin/cursors

Revision: `a7eb08527dcce01010fa0ec46fa2bc4c3154f0d4`. See `catppuccin-pink/LICENSE`.

GPL-2.0. Volantes shapes by Alexey Varfolomeev and Catppuccin contributors (see AUTHORS). Templates colored with the official Mocha Pink palette: pink #f5c2e7, base #1e1e2e. Closed-hand telemetry uses the theme’s all-scroll asset.
